# 联境 V2.0 · 独立法人业务平台原型

在线预览：https://xingyuzhang65-cloud.github.io/new-system/

## 已确认边界
安速、天图、美仓不属于同一法人，客户不重合，运输渠道与仓库资源不共用。平台统一软件模块、操作入口和规则配置能力，各法人分别管理客户、合同、订单、价格、资源、费用和账套。正式法人名称待确认，界面使用品牌作为空间标识。

## 设计依据
结合用户提供的岗位流程图，映射产品、销售、核价、跟单、国内仓、港前、港后、FBA调度、海外仓及财务板块。原图按岗位展开，三个空间的归属是新版产品配置建议，需实施时确认。

- 安速、天图分别配置国内仓、配柜报关、港后运踪等头程履约模块。
- 美仓配置海外仓、特殊仓储与尾程调度；拦截、暂存、自提、一件代发参考业务图，退换货及清货来自此前需求补充。
- 历史跨品牌资源关系不沿用，不将单个品牌赔付规则复制给其他法人。
- 不预设内部结算或法定合并报表，未来真实法人间交易另行确认合同与双方应收应付。

原始画板、个人信息、真实费率、金额、赔付比例及凭证未发布。公开演示只包含抽象业务流程与模拟数据。

## 运行
Node.js 20+，无需安装依赖。运行 npm start，打开 http://127.0.0.1:4206 。运行 node verify.mjs 验证空间隔离、流程和页面。GitHub Pages 从 main 分支根目录发布。

## 可体验操作
切换独立空间、查看架构板块映射、二级菜单字段与规则、搜索筛选、新建订单、记录处理依据并推进流程、补齐资料解除阻塞、创建特殊仓储申请、模拟报价、导出当前法人列表、作业角色隐藏财务及价格、订单阶段统计。

## 原型边界
全部业务数据为模拟示例。二级页面中的关联记录演示同一对象在不同环节中的处理，尚未实现真实单证校验、审批、自动仓储和财务作业。状态推进仅用于演示。

角色与空间切换是前端演示，不构成生产权限控制。正式系统需服务端租户隔离、鉴权、字段权限、跨法人关联校验和审计。正式主体、人员授权、资源清单、财务与赔付规则版本、旧系统主责及迁移范围仍待确认。

V2使用浏览器存储键 lj-independent-v2，不读取旧版跨品牌数据。清除该键恢复默认示例；浏览器业务数据不上传GitHub或真实系统。
