# 联境 · 跨境物流业务中台原型

安速 × 天图 × 美仓集团业务管理端交互原型。基于产品架构初步规划 V1.0 与三张架构、协同流程、菜单参考图制作。

## 运行

安装 Node.js 20 或更高版本，在本仓库运行：

```sh
npm start
```

打开 http://127.0.0.1:4206 。无需安装第三方依赖。`npm run check` 检查前端语法。

## 原型范围

- 工作台：经营指标、品牌趋势、协同待办、跨品牌履约链路、最近订单。
- 十个一级业务中心与对应二级菜单：客户、产品、报价、订单、运输、仓储、结算、数据、系统管理。
- 订单：按品牌和状态筛选、即时搜索、详情抽屉、新建并在浏览器本地保存、异常处理、CSV 导出。
- 仓储：入库、库存、出库、暂存、拦截、退换货、清货、自提分别展示业务记录和流程说明。
- 角色演示：集团、天图跟单、美仓作业三个视角。业务角色限制菜单与订单范围，隐藏订单成交价。
- 协同待办处理意见在当前会话保存；订单模拟修改使用 localStorage 保存。
- 系统管理提供总体架构视图，展示业务入口、中台、专业履约、分析与基础设施。

## 演示边界

全部客户、金额、库存、事件与指标均为模拟数据。看板指标是固定展示数据，不随新建订单重新计算。各中心示例明细用于讨论信息架构与业务流程；除订单与待办外，不提供真实业务写入。角色切换仅模拟前端可见性，不构成安全权限控制；真实系统需要服务端鉴权、组织隔离、字段授权、审计和财务规则。未接入物流服务商、财务或生产数据库。

浏览器本地存储键为 `lj-orders-v1`，清除该项可恢复默认订单。接口服务仅提供三个静态页面资源，不对外提供业务接口。字体可选从 Google Fonts 加载，离线时使用系统中文字体。
